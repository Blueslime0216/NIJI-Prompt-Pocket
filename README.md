# NIJI Prompt Pocket

NIJI 이미지 생성 프롬프트를 정리하는 Python 콘솔 프로그램입니다. 번호 메뉴로 프롬프트를 추가·검색하고, 즐겨찾기와 참고 이미지의 컬러 픽셀/ASCII 미리보기를 사용합니다.

## 실행

Python 3.10 이상이 필요합니다. 이미지 기능은 Pillow를 사용합니다.

```bash
git clone https://github.com/Blueslime0216/NIJI-Prompt-Pocket.git
cd NIJI-Prompt-Pocket
python -m pip install -r requirements.txt
python main.py
```

Windows에서는 `run.cmd`를 더블클릭해도 실행됩니다. `python` 명령이 없으면 `py -3`으로 바꿔 사용하세요. 추가 설치 없이 기본 관리 기능을 사용할 수 있으며, Pillow가 없으면 이미지 기능에서 설치 안내가 표시됩니다.

## 사용 방법

- **1. 프롬프트 추가**: 제목 → 내용 → 카테고리 → 선택 이미지 경로를 입력합니다. 내용은 여러 줄로 입력할 수 있으며, 마지막에 마침표 `.` 하나만 입력한 뒤 Enter로 완료합니다. 입력 중 언제든 **Esc**를 누르면 추가 전체를 취소합니다.
- **2. 전체 목록**: 원본 번호, 제목, 카테고리, 즐겨찾기 `⭐`를 표시하며 번호를 입력하면 바로 상세 보기를 엽니다.
- **3. 카테고리별 조회**: 선택한 카테고리의 프롬프트를 표시하고 번호로 상세 보기를 엽니다.
- **4. 키워드 검색**: 제목과 내용에서 대소문자를 구분하지 않고 검색하며, 결과 번호로 상세 보기를 엽니다.
- **5. 상세 보기 / 이미지 미리보기**: 전체 내용과 참고 이미지의 미리보기를 표시합니다.
- **6. 즐겨찾기 추가 / 해제**: 프롬프트 번호로 상태를 전환합니다.
- **7. 즐겨찾기 목록**: 즐겨찾기한 프롬프트를 모아 보고 번호로 상세 보기를 엽니다.
- **8. 참고 이미지 연결 / 교체 / 해제**: 기존 프롬프트에도 이미지 한 장을 연결할 수 있습니다.
- **9. 이미지 표시 방식 변경**: 흑백 ASCII, 컬러 ASCII, 컬러 픽셀을 선택합니다.
- **10. 프롬프트 삭제**: 목록에서 번호를 고르고 확인하면 삭제합니다. 확인 화면에서 `0`을 선택하면 취소합니다.
- **0. 종료**: 프로그램을 종료합니다.

목록이나 검색 결과에서는 **표시된 프롬프트 번호를 입력하면 상세 내용과 이미지가 바로 열립니다.** 상세를 본 뒤에도 같은 결과 목록에서 다른 번호를 계속 선택할 수 있습니다. **Enter 또는 `0`**을 입력하면 메뉴로 돌아갑니다. 현재 결과에 없는 번호는 선택할 수 없으며, 필터링한 목록의 번호는 전체 목록의 원본 번호와 같습니다.

프롬프트 추가·즐겨찾기 토글·이미지 연결·표시 방식 변경·빈 결과는 별도 Enter 대기 없이 메뉴로 돌아갑니다. 즐겨찾기/이미지 대상과 조회 카테고리 선택에서 `0`은 취소입니다. 추가할 때의 카테고리 선택에서 `0`은 직접 입력입니다. 메인 메뉴의 `0`은 프로그램 종료입니다.

각 기능이 끝나 메인 메뉴로 돌아오면 터미널 화면을 정리해 메뉴를 위쪽에 다시 표시합니다. 간단한 작업 결과나 저장 상태 한 줄은 메뉴 위에 남습니다.

대화형 터미널에서는 새 기능을 열거나 목록에서 다른 상세 항목을 선택할 때도 화면을 정리해 내용을 위쪽에서 보여줍니다. 잘못된 입력 안내는 다시 고칠 수 있도록 남겨둡니다. 출력이 파일로 연결된 경우 화면 정리 명령은 실행하지 않습니다.

**프롬프트 추가, 삭제, 즐겨찾기, 이미지 연결은 자동 저장되어 재실행 후에도 유지됩니다.** 저장 파일은 `local-data/prompts.json`이며 `.gitignore`에서 제외되어 공개 저장소에 올라가지 않습니다. 다른 데이터 폴더를 쓰려면 `NIJI_PROMPT_POCKET_DATA_DIR` 환경 변수로 경로를 지정하세요. 지정 폴더를 프로젝트 안에 두면 `.gitignore` 규칙도 확인해 주세요. JSON이 손상되면 원본 저장 파일을 덮어쓰지 않고 기본 데이터로 실행하며 저장 오류를 알립니다. 원본 이미지 파일은 변경하지 않습니다.

## 기본 프롬프트와 카테고리

사용자가 제공한 아래 프롬프트 3개를 `seed_data.py`에 등록했습니다. 문구와 NIJI 옵션은 제공된 그대로 보관하며, 이 프로그램이 NIJI에 전송하거나 이미지를 생성하지는 않습니다.

- Live2D 전신 캐릭터 (chaos 40): `VTuber, full-body pose, girl, Live2D --chaos 40 --ar 2:3 --niji 7`
- Live2D 전신 캐릭터 (기본): `VTuber, full-body pose, girl, Live2D --ar 2:3 --niji 7`
- 애니메이션 클로즈업 장면: `anime screencap, anime episode still, girl, close-up, cinematic lighting, 8k, high resolution --ar 16:9 --niji 7 --raw --stylize 200 --profile 7ztapke`

기본 3개는 모두 **이미지 생성** 카테고리입니다. 선택 가능한 기본 카테고리는 텍스트 생성, 이미지 생성, 영상 생성, 페르소나, 자동화, 기타이며, 새 카테고리도 직접 입력할 수 있습니다.

기본 데이터를 바꾸려면 `seed_data.py`의 `SAMPLE_PROMPTS`를 수정하세요. 각 딕셔너리는 `title`, `content`, `category`, `favorite`, `image_path`를 갖습니다.

## 참고 이미지

기본 프롬프트별 이미지 3장이 `assets/`에 포함되어 있습니다. 공개용 이미지에서 작성자·설명·XMP 메타데이터는 제거했고 픽셀은 그대로 보존했습니다.

- PNG, JPG, WebP 등 Pillow가 지원하는 로컬 이미지 파일을 사용합니다. 애니메이션은 첫 프레임을 보여 줍니다.
- 이미지 경로에 공백이나 한글이 있어도 사용할 수 있습니다. 탐색기의 **경로로 복사**로 얻은 따옴표 포함 경로도 지원합니다.
- 상대 경로는 항상 이 프로젝트 폴더 기준입니다. 예: `assets/sample-01.png`.
- 이미지 경로 입력에서 **Enter**는 현재 연결 유지 또는 건너뛰기, **`-`**는 연결 해제입니다.
- 개인 이미지는 `local-images/`에 두면 Git에서 제외됩니다. 연결은 파일 경로만 보관하며 파일을 복사하거나 업로드하지 않습니다.
- 색상을 지원하는 터미널에서는 **컬러 픽셀**이 기본입니다. `▀` 문자의 글자색과 배경색에 위/아래 두 픽셀을 넣어, 한 문자 칸에 세로 두 픽셀을 표시합니다.
- `9`번 메뉴에서 **흑백 ASCII / 컬러 ASCII / 컬러 픽셀**을 바꿀 수 있습니다. ANSI 24비트 색상을 사용하며, VSCode 터미널이나 Windows Terminal에서 컬러로 볼 수 있습니다.
- 출력이 파일로 리디렉션되거나 색상을 지원하지 않는 환경, `NO_COLOR` 환경 변수가 설정된 경우에는 흑백으로 표시합니다.
- 이미지 방향과 문자 비율을 보정합니다. 작은 미리보기이므로 원본의 모든 세부 표현까지 재현하지는 않습니다.
- 이미지가 이동·삭제되거나 손상되면 안내를 표시하고 프롬프트 기능은 계속 사용할 수 있습니다. 최대 2,000만 픽셀을 지원합니다.

## 파일 구성

- `main.py`: 메뉴, 입력 검증, 추가·목록·검색·즐겨찾기·이미지 연결
- `seed_data.py`: 기본 프롬프트와 카테고리
- `image_preview.py`: 이미지 경로 확인 및 ASCII 변환
- `terminal_support.py`: 터미널 컬러 지원 확인, Windows ANSI 활성화, 대화형 화면 정리, Esc 취소 입력
- `prompt_storage.py`: 프롬프트 로컬 JSON 저장과 불러오기
- `assets/`: 메타데이터를 제거한 기본 참고 이미지
- `tests/test_prompt_pocket.py`: 콘솔 및 이미지 기능 회귀 테스트
- `docs/LEARNING.md`: Python 구조와 Git 명령 설명
- `submission/README.md`: 제출 안내
- `run.cmd`: Windows 실행 파일

```bash
python -m unittest discover -s tests -v
```

빈 입력·잘못된 번호·검색과 즐겨찾기의 번호 유지·프롬프트 저장·여러 줄 입력·이미지 연결/해제·손상 이미지·Pillow 미설치·다른 폴더에서 실행을 확인합니다.

기능별로 커밋을 나누었으며 `feature/prompt-list` 브랜치에서 목록 기능을 개발한 뒤 `main`에 병합했습니다. 다음 명령으로 기록을 확인할 수 있습니다.

```bash
git log --oneline --graph --all
```

`_dev/`, 작업 안내 파일, 환경 변수 파일, 개인 이미지, `local-data/` 저장 파일, 로컬 실행 기록과 스크린샷은 `.gitignore`에서 제외합니다. 공개 저장소에는 프로그램과 공개용 샘플, 사용 안내, 테스트를 보관합니다.
